## 这是什么

Zhrradiant SrvMap 是个给 L4D2 玩家用的 Windows 桌面工具。不用开浏览器，在客户端里就能看服务器状态、挑想玩的服，点一下直接连进游戏。

---

## 功能一览

### 服务器浏览

- **服务器组**：由站点用户创建维护的服务器列表，可以整组收藏，关注的组一眼就能找到
- **公共服务器**：所有公开服务器都在这，能搜、能筛（在线/空闲、官图/三方图、游戏模式），按人数排序，一页页翻
- **组详情**：组里能看到描述、头像，还有自定义按钮和图片

### 服务器状态查询

默认走云端拿服务器信息，也能切成本地模式（A2S 协议直连）自己查。能看到：

- 在不在线、当前地图、玩家数 / 上限
- 在线玩家列表（名字、分数、在线时长）
- 游戏模式、VAC 状态、服务器版本

云端和本地两种模式，点一下就能切。

### 热门统计

- 近 3 天热门三方地图排行榜（Top 20）
- 排名是升了还是新上榜，都有标记
- 热门服务器排行
- 点排行榜上的地图名，直接跳到地图详情

### 地图模块

- **地图库**：用来浏览三方地图，能搜，也能按标签、标记筛
- **标签系统**：用纯色标签标地图特性（写实、多特、变态之类）
- **评分**：5 星制，显示平均分和评分人数
- **评论**：能评论地图，也支持回复
- **收藏夹**：可以建好几个收藏夹分类管地图，支持批量操作
- **分享码**：把收藏夹生成分享码发给朋友，对方一键导入
- **在线状态**：看哪台服务器正在跑某张地图
- **下载链接**：直达 Steam Workshop 下载页
- **个人标记**：标上“玩过”“喜欢”“不喜欢”

### 服务器收藏

- 建多个收藏夹，把常玩的服务器分类放好
- 从公共服务器、组服务器、历史记录里一键添加
- 支持批量操作（多选添加/移除）
- 服务器收藏也能生成分享码，把列表发给朋友

### 连接历史

- 通过客户端连过的每台服务器都会自动记下来
- 可以逐条删，也能一键清空
- 想再连就直接从历史里找，不用重新翻

### 下载管理

- 地图文件有下载队列，支持暂停和取消
- 进度和下载速度实时显示
- 下载目录自己定，一键打开

### 自动更新

- 启动时静默检查有没有新版本
- 有新版本就弹窗，告诉你更新了啥和版本号

### 一键进游戏

点任意服务器卡片看详情，再点“连接服务器”，会自动唤起 Steam 进游戏，不用手动复制 IP。

## 安装与使用

### 下载

去 [Releases](https://github.com/Zhrradiant/zhrradiant-srvmap/releases) 页面，下载最新的 `Zhrradiant SrvMap.exe`。

### 使用

1. 双击运行
2. 用竹烨柠檬的站点账号登录（没有账号点“注册”跳转）
3. 浏览服务器，点开详情，一键连进游戏

### 系统要求

- Windows 10 及以上
- Steam 客户端（连服务器要用）
