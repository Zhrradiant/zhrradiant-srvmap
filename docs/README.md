## 这是什么

Zhrradiant SrvMap 是给 L4D2 玩家用的 Windows 桌面工具。打开这个客户端就能看服务器状态、挑想玩的服，点一下就进游戏

平时找服就三步：找服、看状态、点连接

---

## 功能一览

### 服务器浏览

- **服务器组**：站点用户建好、维护的服务器列表，可以收藏组，常关注的组一眼就能找到
- **公共服务器**：所有公开服务器都在这，能搜索、能筛选（在线/空闲、官图/三方图、游戏模式），也能按玩家数排序、翻页
- **组详情**：看组的描述、头像、自定义按钮和图片

### 服务器状态查询

默认走云端拿服务器的实时信息，也可以切到本地模式（A2S 协议直连）自己抓数据：

- 在线状态、当前地图、玩家数 / 上限
- 在线玩家列表（名称、分数、在线时长）
- 游戏模式、VAC 状态、服务器版本

"云端"和"本地"两种模式随时切换

### 热门统计

- 近 3 天热门三方地图排行榜（Top 20）
- 排名变化趋势标记（上升 / 新上榜）
- 热门服务器排行
- 排行榜上的地图名，点一下就能进地图详情

### 地图模块

一个完整的地图社区：

- **地图库**：浏览三方地图，能搜索，能按标签/标记筛
- **标签系统**：纯色标签标出地图特性（写实、多特、变态等）
- **评分**：5 星制，显示平均分和评分人数
- **评论**：地图评论，支持回复
- **收藏夹**：建多个收藏夹分类管地图，能批量操作
- **分享码**：把收藏夹生成分享码发给朋友，对方拿到码直接导入
- **在线状态**：看哪些服务器现在正在跑某张图
- **下载链接**：直达 Steam Workshop 下载页
- **个人标记**：标"玩过""喜欢""不喜欢"

### 服务器收藏

- 建多个收藏夹，把常玩的服务器分类放好
- 从公共服务器、组服务器、历史记录里随手加进来
- 能多选批量添加/移除
- 收藏夹也能生成分享码，把你的服务器列表发给朋友

### 连接历史

- 自动记下你连过的每一台服务器
- 逐条删，或者直接清空
- 想再玩哪台，从历史里点一下就能连，不用到处找

### 下载管理

- 地图下载队列，能暂停、能取消
- 进度和速度实时显示
- 下载目录自己定，点一下就能打开

### 自动更新

- 启动时静默检查有没有新版本
- 有更新就弹窗，告诉你更新内容和版本号

### 一键进游戏

点开任意服务器卡片看详情，再点"连接服务器"，会自动拉起 Steam 进游戏，不用手动复制 IP

## 安装与使用

### 下载

前往 [Releases](https://github.com/Zhrradiant/zhrradiant-srvmap/releases) 页面，下载最新版本的 `Zhrradiant SrvMap.exe`

### 使用

1. 双击运行
2. 用竹烨柠檬的站点账号登录（没有的话点"注册"跳转）
3. 浏览服务器 → 点详情 → 连接进游戏

### 系统要求

- Windows 10 及以上
- Steam 客户端（连服务器要用）
